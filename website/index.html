11 Skills, One Agent

Each skill is a self-contained capability with its own permissions, approvals, and sandbox.

🌐 Browser

Navigate, click, type, extract, screenshot. Playwright-backed with mock driver for testing.

💻 Computer

System info, process list, window management, clipboard, notifications.

📁 Filesystem

Read, write, list, glob, search, watch. Workspace-scoped with permission gates.

🐙 Git

Clone, status, diff, commit, push, branch, log. Repository-aware operations.

🖥️ Shell

Command execution with timeout, streaming output, workspace cwd, env isolation.

🧠 Memory

Persistent key-value store with TTL, namespaces, and query API.

🔍 Research

Web search via multiple engines, content extraction, synthesis, citations.

⏰ Scheduler

Cron expressions, one-off tasks, recurring jobs, timezone-aware, job history.

🔎 Search

Local file search (ripgrep), web search, semantic search over memory.

📄 Documents

PDF text extraction, Office docs, OCR via Tesseract, chunking for RAG.

Model Providers

Pluggable model abstraction. Swap providers without changing agent code.

Mock

Deterministic responses for testing. Zero API keys, zero latency.

Ollama

Local LLMs (Llama 3.1, Mistral, CodeLlama, etc.). Full privacy, no internet.

OpenAI Compatible

OpenAI, Azure, Together, Fireworks, DeepSeek, any OpenAI-compatible endpoint.

Router

Smart routing: mock → local → cloud. Fallback chains, cost optimization.

Bring your own model

Configure via JQC_MODEL_PROVIDER and JQC_MODEL_NAME. Supports OPENAI_API_KEY, OLLAMA_HOST, custom headers.

Privacy by Default

Hybrid Privacy Mode

Local processing by default. Cloud calls only with explicit approval. Configurable per-skill.

Approval Gates

Prompt before any external action: network, file write, shell exec, model call. One-click approve/deny.

Demo Mode

Runs with mock drivers and local models only. Perfect for evaluation without API keys.

Data Isolation

SQLite database at ~/.jawa-quant-computer/jqc.sqlite3. No cloud sync. Delete the folder to wipe everything.

No Telemetry

Zero analytics, zero crash reporting, zero update checks. The only network traffic is what you explicitly trigger.

Architecture

Modular, testable, extensible. Skills, models, and orchestration are all pluggable.

src/jqc/
jqc/ ├── cli.py # CLI entry & REPL ├── config.py # Pydantic settings (JQC_ prefix) ├── app.py # Application lifecycle ├── core/ │ ├── errors.py # JqcError, ApprovalRequired, etc. │ └── schemas.py # Pydantic models for all I/O ├── security/ │ ├── permissions.py # Capability-based permissions │ └── secrets.py # Secret store (keyring-backed) ├── models/ │ ├── base.py # BaseLLM abstract class │ ├── mock.py # Deterministic test model │ ├── ollama.py # Local Ollama client │ ├── openai_compat.py # OpenAI-compatible HTTP client │ └── router.py # Fallback chain & routing ├── skills/ │ ├── base.py # Skill, SkillContext, SkillResult │ ├── browser.py # Playwright + mock driver │ ├── computer.py # psutil + platform APIs │ ├── filesystem.py # Workspace-scoped FS ops │ ├── git.py # GitPython wrapper │ ├── shell.py # asyncio subprocess │ ├── memory.py # SQLite KV store │ ├── research.py # Search + extraction │ ├── scheduler.py # APScheduler integration │ ├── search.py # Local + web search │ ├── documents.py # PyPDF2, python-docx, OCR ├── orchestrator/ │ ├── planner.py # Task decomposition │ ├── agent.py # Main agent loop │ ├── verifier.py # Result validation │ └── events.py # Event bus ├── scheduler/ │ ├── service.py # Background job runner │ └── times.py # Cron parsing, timezone handling ├── api/ │ └── server.py # FastAPI REST + WebSocket └── storage/ ├── db.py # SQLite schema & migrations └── repos.py # Repository pattern

$ pip install -e ".[dev]"
$ jqc
