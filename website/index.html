03 / Run it yourself

Start from the source.

Python 3.11 or later. Real browser use also needs Playwright Chromium installed.

Clone the repository, then use the commands below. Review the README before connecting external services.

SOURCE CHECKOUT
git clone https://github.com/honeyamn10-source/jawa-quant-computer.git
cd jawa-quant-computer
python -m pip install -e ".[dev]"
jawa-quant-computer
# Or start the local web interface:
uvicorn jqc.api.server:app --host 127.0.0.1 --port 8765
04 / Know the scope

Clear expectations.

Alpha software. Demo mode is deterministic; a mock result is not proof of a real browser or model operation. Review permissions before enabling tools on personal data.

See GitHub Actions for commit-specific test and build results.
